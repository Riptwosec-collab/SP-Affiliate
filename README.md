# SP-Affiliate 2.7.2

เว็บ HTML สำหรับจัดการงาน Shopee Affiliate ตั้งแต่รวบรวมหลักฐานสินค้า สร้างโครงบท วางแผนผลิตเนื้อหา ไปจนถึงติดตามผล TikTok / Facebook

## เปิดใช้งาน

1. ดาวน์โหลด repository หรือไฟล์ `index.html`
2. เปิด `index.html` ด้วย Chrome หรือ Edge
3. กด **ลองตัวอย่าง / Try demo** เพื่อดูข้อมูลสมมติที่แยกจากพื้นที่ข้อมูลจริง
4. เปลี่ยนภาษา UI ได้ด้วยปุ่ม **TH / EN**

ไม่ต้องติดตั้ง dependencies หรือสั่ง build ตัวแอปและฟอนต์ฝังอยู่ใน HTML ไฟล์เดียว

## ความสามารถ

- ธีมสว่าง Pearl และธีมมืด Graphite/Cyan/Violet พร้อมโหมดตามระบบ รองรับคอมและมือถือ
- เลือกธีมจากหัวเว็บ เมนูมือถือ หรือหน้าตั้งค่า จำค่าบนอุปกรณ์และคงร่างที่กำลังแก้ไข
- หมวดสินค้าตอนคลังว่างกดเริ่มเพิ่มสินค้าได้ โดยไม่ทับร่างเดิม
- แผนงาน ผลโพสต์ และ A/B มีปุ่มนำไปทำขั้นตอนที่จำเป็นก่อนใช้งาน
- Hero และหมวดสินค้าแบบเลื่อนแนวนอน การ์ดจากสินค้าที่บันทึกจริง และเมนูพื้นที่ทำงานบนมือถือ
- ปุ่ม TH/EN แบบ segmented บันทึกภาษาที่เลือก และคำแปล UI รวมใน src/translations.js
- ปุ่มกระเป๋าเปิดคลังสินค้าที่บันทึกไว้ ไม่มีระบบตะกร้าชำระเงินหรือสินค้าขายสมมติ
- ฟอร์มสินค้า 4 ขั้น พร้อมค้นหา/กรอง และมุมมองการ์ดหรือตาราง
- Autosave ร่างสินค้า/บท แยกตามรายการและแยกโหมดจริง–ตัวอย่าง พร้อมกู้หลังรีเฟรช
- Story Studio แบบแท็บและการ์ดฉาก, Undo/Redo, คืนเวอร์ชันเป็นร่าง, คลัง Hook และโหมดซ้อมอ่านบท
- บันทึกลิงก์ Affiliate เดิม รุ่น ราคา รูป และหลักฐานที่ผู้ใช้ให้
- คะแนนแบบมีกฎคงที่ แยก Opportunity score กับ Evidence coverage; ซ่อนคะแนนรวมเมื่อ coverage ต่ำกว่า 60%
- เปรียบเทียบสินค้า 2–5 รายการ พร้อมเหตุผลและ snapshot หลักฐาน
- Story Studio: 6 มุมเรื่อง โครงบท 15/30/60 วินาที Hook A/B ฉาก Caption และโพสต์ Facebook
- แก้บท เก็บเวอร์ชัน และตรวจรายการก่อนกำหนดสถานะ Ready
- แผน 7/14/30 วัน ตามกำลังผลิต เหลือเวลาสำรองอย่างน้อย 20% และมีลำดับงานก่อน–หลัง
- บันทึกโพสต์และผลแบบ cumulative snapshot ที่อายุ 24h / 72h / 7d
- เปรียบเทียบการทดลองเชิงสังเกต และคำนวณสถานการณ์สมมติจากค่าที่กรอก
- สำรอง/นำเข้า JSON พร้อมตรวจข้อมูล และส่งออกผล CSV

## บัญชี คลาวด์ และบริการออนไลน์

- สมัคร/เข้าสู่ระบบ ยืนยันอีเมล และกู้รหัสผ่านผ่าน Supabase Auth
- บัญชีแต่ละคนมีพื้นที่ในเครื่องแยกจากข้อมูลเดิม สามารถคัดลอกข้อมูลเดิมเข้าบัญชีได้
- ส่ง/รับข้อมูลคลาวด์แบบเลือกเอง เปิด autosync ได้หลังซิงก์ครั้งแรก และหยุดให้ตรวจเมื่อเวอร์ชันขัดกัน
- รับข้อมูลคลาวด์แล้วเก็บสำเนาก่อนซิงก์ให้ส่งออก JSON กู้คืนได้
- Backend และตารางสิทธิ์เจ้าของข้อมูลเผยแพร่แล้ว ดู [คู่มือติดตั้งและสถานะ](docs/cloud-setup.md)
- Shopee/AI มี adapter และหน้าตรวจข้อมูลก่อนใช้ แต่ **ยังไม่มีคีย์และยังไม่ผ่านการเรียกบริการจริง**

## ข้อจำกัด

- **Shopee/AI ยังไม่เชื่อมต่อจนกว่าจะตั้งค่าคีย์และทดสอบจริงสำเร็จ**; ไม่มีการค้นเว็บทั่วไป
- การวิเคราะห์ใช้คะแนนและหลักฐานที่ผู้ใช้กรอก การสร้างบทใช้แม่แบบในเครื่อง
- การดึงชื่อ ราคา รูป และคอมมิชชันต้องใช้บัญชีและสิทธิ์ Shopee Affiliate Open API; ระบบให้ตรวจผลก่อนเติมช่องว่าง
- ต้องตรวจข้ออ้าง แหล่งข้อมูล รุ่น ราคา และเงื่อนไขก่อนใช้บทจริง
- ไม่โพสต์ไป TikTok/Facebook อัตโนมัติ และไม่รับประกันยอดขายหรือความแม่นยำเชิงพยากรณ์
- เก็บ API key บน Supabase Edge Function เท่านั้น ห้ามฝัง secret ใน HTML

## ข้อมูลและการสำรอง

ข้อมูลบันทึกใน IndexedDB ของเบราว์เซอร์เสมอ ไม่ถูกอัปโหลดเข้า repository ข้อมูลบัญชีจะซิงก์เมื่อคุณเลือกส่งขึ้นคลาวด์หรือเปิด autosync; ข้อมูลผู้ใช้ทั่วไปและโหมดตัวอย่างไม่ถูกส่งโดยอัตโนมัติ
ควรส่งออก JSON เป็นระยะ โดยเฉพาะก่อนล้างข้อมูลเบราว์เซอร์ ย้ายไฟล์ หรือย้ายเครื่อง
ร่างและขั้นตอนที่เปิดอยู่ถูกเก็บแยกจากข้อมูลที่ยืนยันแล้ว การบันทึกร่างไม่เปลี่ยนบทเป็น Ready
ไฟล์ JSON รุ่นใหม่รวมร่างที่กู้คืนได้ แต่ไม่รวมประวัติ Undo/Redo; ประวัติ Undo/Redo เก็บในเบราว์เซอร์สูงสุด 60 จุดต่อบท
คืนเวอร์ชันเก่าที่มีเฉพาะข้อความ/ฉากจะคงบรีฟปัจจุบันไว้ ต้องทวน Caption และข้อความ Affiliate อีกครั้ง
หากพื้นที่จัดเก็บไม่พร้อม แอปจะแจ้งข้อผิดพลาดและให้ส่งออก JSON สำรองก่อนปิด

การเปิดผ่าน file URL และการเปิดผ่านเว็บไซต์มีพื้นที่จัดเก็บคนละ origin; ใช้ JSON ย้ายข้อมูลระหว่างกัน

รูปจาก URL ภายนอกจะถูกโหลดจากผู้ให้บริการรูปนั้น หากต้องการใช้งานโดยไม่พึ่งเครือข่าย ให้อัปโหลดรูปจากเครื่องแทน

## พัฒนาและสร้าง HTML ไฟล์เดียว

ใช้ Node.js 22 ขึ้นไป แก้ไฟล์ใน `src/` แล้วรัน:

```sh
npm ci
npm run build
```

`scripts/build.mjs` รวม `src/shell.html`, CSS และ JavaScript ตามลำดับเป็น `index.html` พร้อมฟอนต์ในตัว ไม่มี dependency ตอนใช้งานจริง และไม่เปลี่ยนรูปแบบข้อมูลธุรกิจ v2 เดิม

ติดตั้งเครื่องมือทดสอบเฉพาะตอนพัฒนา:

```sh
npm ci
npx playwright install chromium
npm test
npm run test:cloud
npm run test:storefront
npm run test:server
```

หากมี Chromium อยู่แล้ว ใช้ `CHROMIUM_EXECUTABLE=/path/to/chromium npm test` ได้
`tests/legacy-v2.html` เป็นแอปรุ่นก่อนอัปเกรดสำหรับสร้างข้อมูลทดสอบสมมติและตรวจความเข้ากันได้ ไม่ใช่ข้อมูลส่วนตัวของผู้ใช้

## การตรวจสอบ

ชุดทดสอบ Chromium ตรวจข้อมูล v2 เดิมทั้งชุด, การกู้ร่างหลังรีเฟรช, การสลับภาษา,
การแยก demo/real, ปุ่ม Back, ร่างหลายสินค้า, ฟอร์มที่มีช่องไม่ครบ,
Undo/Redo, คืนเวอร์ชันเก่า/ใหม่, นำเข้าและรวม JSON โดยรักษาเจ้าของร่าง,
ความผิดพลาดการบันทึก, โหมดเปิดไฟล์โดยตรง และความกว้าง 393/768/1440 พิกเซลทั้ง 8 หน้า

### English

A self-contained, bilingual local workspace for evidence-based affiliate planning and tracking.
Download and open `index.html` in Chrome or Edge. No build step is required.
Local evidence and story templates work offline. Optional accounts and revision-aware cloud backup are implemented. Shopee/AI adapters require server credentials and live verification; they remain **not connected**. General web research is not implemented. Export JSON backups regularly. See [cloud setup](docs/cloud-setup.md) for deployment and verification limits.
