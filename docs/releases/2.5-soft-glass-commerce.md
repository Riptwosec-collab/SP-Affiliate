# 2.5 — Soft Glass Commerce

The creator workspace now follows the supplied warm glass direction: graphite, ivory, sage and champagne, a subdued natural workspace background, outline icons, and a prominent paste-link action. The existing application and all eight routes remain in place.

## Changes

- Desktop sidebar, global product search/Shopee-link entry, three-step workflow, category rail, ivory product cards, real task/result summaries and quick tools.
- Product sorting by recency, price, commission or evidence coverage. Unknown values sort last; no record is modified.
- Visible add-product action on populated home screens; choose-product opens Story Studio, image opens product details, copy-link uses the existing clipboard action.
- Background-reduction preference for long working sessions, persisted separately from business data.
- Wider category suggestions including health, mom/baby and books. Saved custom categories and authored content are preserved.
- Mobile bottom navigation and readable stacked panels; existing forms, scene cards and dialogs share the updated colors.
- Modular CSS, embedded compressed WebP and vendored MIT Tabler icons still build to a single offline HTML file. No new runtime dependency.

## Compatibility and verification

Schema version 2, IndexedDB/store identity, backup format, real/demo separation, account isolation and existing deployment configuration are unchanged.

Final verification: 49 passing tests — 15 upgrade/offline/draft tests, 12 storefront tests, 7 cloud tests, 11 server/database tests and 4 catalogue tests. The import test hit its existing 5-second timeout once; it passed both the isolated retry and the full final suite. The teleprompter test now waits for visible clock progress instead of a fixed 1.2-second sleep.

Visual QA: `design-qa.md`. Direct browser checks confirmed home, demo, global search and sorting. Responsive coverage includes 320–1440px, both languages and all routes; the reference comparison uses 1536 × 1024. Physical Safari remains untested.

## Honest boundaries

Shopee/AI remain disconnected until configured and working. URL entry still validates Shopee Thailand links. No TikTok/Lazada adapter, automatic publishing, paid PRO tier, unsourced discounts, invented revenue, recommendation ranking, or favorite state is implied by the design. Existing analytics uses actual logged 72-hour snapshots and post attribution. Product images and data are never fabricated for the real workspace.
