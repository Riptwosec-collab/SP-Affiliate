# SP-Affiliate 2.7 — Premium Editorial Commerce

The previous dark decorative presentation competed with product content. This release adopts the supplied light editorial brief across the existing workspace.

## Changes

- White/light-gray surfaces, dark type, blue actions, restrained shadows and generous spacing.
- Editorial hero, compact navigation, floating categories and native horizontal product cards; list mode remains available.
- Consistent product forms, Story Studio scene cards, planner, results, lab and settings.
- Responsive TH/EN layout from 320px upward, keyboard-accessible product rail, visible focus and reduced motion.
- Dedicated `src/editorial.css` presentation module, compiled with the existing modules into standalone `index.html`.
- Removed decorative artwork from the generated bundle without deleting existing source assets.

## Compatibility

All existing routes, categories, authored content, affiliate links, data schema, autosave/recovery, history, backup/import and optional account/provider flows remain intact. Shopee and AI do not claim a verified connection without one. No dependencies or deployment settings changed.

## Validation

54 tests passed: storefront 15, upgrade 15, cloud 7, server/database 11 and catalogue 6. The responsive matrix checks eight routes, both UI languages and seven widths (320–1920px). Visual inspection covered home, product form, Story Studio and settings. See `design-qa.md` for scope and limitations.
