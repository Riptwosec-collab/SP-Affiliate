# SP-Affiliate 2.4 — Creator Studio

The home screen now prioritizes starting a product brief, continuing a draft, and opening recent stories. The Graphite / Cyan / Violet design uses one desktop sidebar and a four-item mobile navigation bar. Existing product analysis, story scenes, Undo/Redo, revisions, planning, results, experiments, account isolation and backups remain available.

## Catalogue metadata

- Products may have optional `category` (120 characters), `brand` (120), and `tags` (500) strings. Edit them in the first product-form step. Category suggestions allow arbitrary user-defined values.
- Home category filters and counts come from the current workspace's actual records. Products without metadata are shown as Uncategorized; existing records are not inferred, relabelled or migrated on read.
- Library search includes category, brand and tags. Category filtering combines with status and evidence filters.
- Schema version 2 and IndexedDB identity remain unchanged. JSON import validates optional metadata, accepts old backups, and preserves authored text in both interface languages.
- The home link shortcut retains autosave and will reopen an existing unfinished product instead of replacing its link with a different one.

## Delivery

`npm run build:site` still produces one self-contained `index.html`, with embedded fonts, JavaScript and styles. Remote images and optional online services require their existing connectivity. Shopee/AI status remains disconnected unless the corresponding service is actually available. No new service, dependency, request loop, CI workflow, hosting domain or deployment path was added.

## Verification

- 15 existing workflow tests: legacy data, drafts, refresh, TH/EN, history, revisions, import/export and offline HTML.
- 10 storefront tests: dynamic categories, metadata persistence/search/import, invalid links, draft protection, escaping, keyboard navigation and responsive layouts (320/390/768/1024/1440 px, TH/EN, all eight routes).
- 7 cloud workflow tests, using the existing mock service fixture.
- 11 server/provider/database tests, including PostgreSQL RLS and missing-provider status.
- 4 catalogue unit tests: legacy records, metadata round trip, input validation and preservation of authored content.
- Fresh desktop/mobile screenshots inspected. Real iPhone/Safari hardware was not tested.

The first parallel regression run timed out in JSON import; its isolated rerun and the subsequent full sequential 15-test run passed. The old test's product navigation selector was scoped to the visible sidebar after the header catalogue shortcut was removed from display.
